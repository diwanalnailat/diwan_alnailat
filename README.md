# ديوان النائلات

منصة عربية لإدارة مشاركة منقية النائلات للشيخ عبدالله بن عامر النهدي: مشروع لكل موسم، لجان مستقلة، مهام واعتمادات، مصاريف وعهد مالية، أصول وموردون وملفات إعلامية تمتد عبر المواسم.

ابدأ من [تسليم كوديكس](docs/CODEX_HANDOFF.md). حالة التشغيل ومتطلبات الربط في [مراجعة الجاهزية](docs/READINESS.md)، والعقود البرمجية في [واجهات البيانات](docs/API_CONTRACT.md).

الصفحة التعريفية أصبحت React ضمن Next.js على `/heritage`. راجع [تشغيل Next.js وحدود النقل](docs/NEXT_MIGRATION.md). تشغيل التطوير يحتاج Node.js 22.22.2 أو أحدث ويحتفظ بمساحة العمل والخلفية الحالية.

## الوضع الحالي

تعمل النسخة على Sites بصورة خاصة. البيانات في D1 والمرفقات الخاصة في R2، والمصدر في مستودع الموقع نفسه. لا تنشئ موقعًا أو قاعدة بديلة للتحديث. الدخول بهوية Sites؛ توثيق الجوال بواتساب يربط هذه الهوية بالعضو، ولا يشكل تسجيل دخول مستقلًا بالجوال.

سند له سياسة مخصصة للديوان وأدوات للبحث والقراءة والتلخيص وإعداد مسودات المهام والمصاريف والموردين والأصول والأدلة. تشغيله والصوت وواتساب يحتاج إعدادات المزود واختبارًا فعليًا. لا توجد رموز دخول ثابتة أو ردود ذكاء اصطناعي وهمية.

## قواعد العمل

- ينسخ الموسم التالي هيكل اللجان وبنودها واختصاصاتها دون العضويات أو المهام أو المبالغ السابقة.
- الصلاحيات على الخادم: منح مباشر أو حزمة أو عضوية لجنة؛ المنع الصريح يسبق السماح، وتراجع الحدود في كل طلب.
- مدير اللجنة يراجع إنجاز المهام. المصروف يمر بالمدير ثم المعتمد الثاني المحدد في اللجنة من مستخدم يملك صلاحية الاعتماد. بديل إداري يعالج تعارض المصالح؛ لا يختاره رافع المصروف ولا يعتمد الشخص مصروفه.
- إثبات المصروف مطلوب عند الإرسال، وربطه بمهمة اختياري. الاعتمادان يخصمان من العهدة تلقائيًا؛ الدفع الشخصي يبقى مستحقًا حتى تسجيل السداد وإرفاق إيصال.
- الأصول لها كميات وحركات وتسليم واسترداد وأرقام وباركود وصور وخريطة. الملفات الإعلامية تحفظ الحسابات ورصد المتابعين وأعمال كل موسم؛ المشاركات المحجوبة لا تظهر في القراءة أو التصدير أو الملفات.
- النقود أعداد صحيحة بالهللة. منع تكرار الطلبات وتعارض الإصدارات والقيود الذرية تحمي الأرصدة.
- محادثات سند تحذف شخصيًا أو تنظف بعد المدة المحددة. الصيانة تجهز تذكيرات المواعيد وتكشف إرسال واتساب غير المؤكد.

## التطوير المحلي

```sh
npm ci
npm test
npm run build
npm run dev
```

التطوير على `127.0.0.1:4173` فقط. عند ضبط `DATABASE_URL` في `.env.local` تستخدم مساحة العمل Supabase PostgreSQL والمرفقات Supabase Storage الخاص؛ راجع [إعداد Supabase](docs/SUPABASE.md). دون هذا المتغير تستخدم SQLite في `/tmp/diwan-local` أو `DIWAN_LOCAL_DATA`. هوية المطور المحلية لا تدخل الإنتاج. البناء يولد `generated.js` و`dist/`؛ لا تعدلهما يدويًا. ملفات البيئة لا تدخل Git.

بعد فتح الديوان: **الإعدادات ← الربط والتكاملات ← فحص جاهزية الديوان**، و**الإعدادات ← تخصيص سَنَد**. راجع [التشغيل](docs/OPERATIONS.md) و[التحقق](docs/VALIDATION.md).
