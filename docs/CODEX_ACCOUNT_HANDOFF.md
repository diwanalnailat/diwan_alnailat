## ما تم

- ربط Supabase PostgreSQL وStorage الخاص، وربط Green API، وتثبيت حساب الإدارة. المستخدم أكد نجاح دخول واتساب سابقًا.
- `/join`: الاسم والجوال برمز دولة ثابت +966 والسبب واللجنة أو الديوان مباشرة، مع موافقة على سياسة مرقّمة وإثبات الجوال عبر OTP.
- قسم طلبات الانضمام وسياسة الانضمام في لوحة التحكم. الإدارة تقبل/ترفض أو توجّه الطلب لمشرف في اللجنة نفسها. لا يراه المشرف إلا بعد توجيهه إليه، مع تطبيق الصلاحيات في الخادم.
- القبول ينشئ/يربط عضوًا بالاسم والجوال، دون منحه صلاحيات إدارة عامة. طلبات الإدارة تولّد إشعارًا مختصرًا عبر مسار الإشعارات الموجود.
- أصلحنا رفض Origin المحلي عند استخدام 127.0.0.1 بدل localhost، دون تخفيف حماية الإنتاج.
- تحسينات السرعة: جمع حدود OTP في استعلام واحد بدل أربعة، جمع الكتابة وحارس عدد الصفوف في PostgreSQL، قراءات مستقلة متزامنة، مجمع اتصالات محدود بأربعة، إعادة استخدام الاتصال عبر HMR والاحتفاظ به محليًا عشر دقائق.
- `vercel.json` يحدد `syd1` لأن قاعدة البيانات الحالية في `ap-southeast-2`. يصبح الإعداد مؤثرًا عند نشر النسخة؛ لا تنقل قاعدة البيانات تلقائيًا.

- ترحيل SQLite المقابل `drizzle/0006_join_requests.sql` محفوظ مع التاريخ والـ snapshots. لا تعدّل الترحيلات التاريخية.

## نقطة الاستكمال وما بقي غير مثبت

1. آخر اهتمام للمستخدم هو بطء إرسال الرمز وتأكيد طلب الانضمام. طبّقنا التحسينات، لكن لم نقس التدفق الكامل مع إرسال واتساب حقيقي بعدها. لا تدّعِ أن الأداء النهائي صار فوريًا.
2. قياس الخيارات المحلية بعد HMR: HTTP 200، نحو 3.5 ثانية لاتصال جديد و0.73 ثانية لاتصال جاهز. هذه ليست مدة إرسال/تأكيد OTP. السجل قبل التحسين أظهر إرسال رمز في 14.9 ثانية.
3. رفضت سياسة الأدوات أمرًا مركبًا لإيقاف السيرفر بالقوة وإعادة تشغيله. لم تتوقف العمليات. Next حمّل تغييرات الانضمام تلقائيًا، لكن Worker المحلي القديم يحتاج إعادة تشغيل لاحقًا لتحميل JS المعدّل؛ لا تتحايل على رفض الأدوات.
4. لا توجد نتيجة موثقة لقبول طلب حقيقي كامل بعد آخر تحسينات الأداء، ولا تحقق من النشر العام لهذه النسخة. GitHub مرتبط بفيرسال وقد يطلق الرفع نشرًا تلقائيًا؛ تحقّق من حالة النشر قبل الادعاء أن النسخة العامة محدثة.
5. لا ترسل رسائل واتساب تجريبية لأرقام فعلية دون حاجة واضحة. لا تكرر فحوصًا نجحت على المدخلات نفسها؛ المستخدم طلب صراحة تقليل التوكن والاختبارات غير المفيدة.
